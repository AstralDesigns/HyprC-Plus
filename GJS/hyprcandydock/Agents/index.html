Dock & App-launcher with SearXNG
Features SearXNG web-search preventing tracking and profiling, plus a coding workspace. Icons can be rearranged and pinned/unpinned natively without editing config files, as desktop icons, the dock, and launcher are fully linked.
Switcheroo Discrete GPU Launch
Integrated switcheroo-control for discrete GPU execution on hybrid graphics laptops. Both dock and launcher offer right-click actions and application minimization to a hidden special workspace.
Candylock Screen
Custom advanced lock-screen supporting notification toasts, live background video, MPRIS media playback controls, weather telemetry, and hardware system monitors.
Bluetooth & Native File Sharing
Startmenu Bluetooth integration featuring native file sharing support and automated device pairing directly from the desktop panel.
Official Setup

Installation

Recommended to run the HyprCandyPlus installer from Hyprland, though it works from other DEs or the TTY. Install using an AUR helper such as paru or yay.

1

Install Required Packages via AUR Helper

Needed packages via your AUR helper (e.g. paru or yay): git, hyprland, kitty, and hyprcandy-install.

$AUR_HELPER -S git hyprland hyprcandy-install kitty
2

Launch Hyprland Session & Terminal

Start your Hyprland session and open the kitty terminal with SUPER + Q.

3

Run the Installer Command

Execute the installed binary directly in your terminal:

hc-install

HyprCandy Workspace BYOK free-trial

Custom HC+ editor seamlessly integrated into the overlay launcher with local models via Ollama and BYOK cloud model compatibility.

workspace.preview Overlay Layer
HC+ Editor Overlay Layered Launcher Local Ollama BYOK Cloud Models

HyprCandy Workspace is a custom HC+ editor themed to match your desktop and directly integrated into the overlay layered launcher so it can be invoked over any active window. The workspace offers two dedicated mode options: Local models via Ollama in an always free tier with models' capability based on user hardware, and BYOK (bring your own key) for advanced users with their own API keys with a small charge to support consistent maintenance of the HyprCandy Agent Workspace's compatibility with cloud models from various providers.

Note: Users intending to use the BYOK approach can grab a 1 week free trial license key via the 'BYOK free-trial' cart buttons.

No Telemetry or Profiling

The HyprCandy+ configuration integrates SearXNG for web searches to explicitly prevent tracking, ad targeting, and user profiling. We do not collect, store, or sell any personal browsing data or desktop analytics.

Local Data Storage

All custom configurations, user wallpapers, and lock-screen preferences are stored strictly on your local Arch Linux filesystem in ~/.config.
